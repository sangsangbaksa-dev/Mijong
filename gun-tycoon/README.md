# 탄피상회: 밤의 사냥꾼

낮에는 넓은 들판에서 자원을 모으고, 밤에는 사방에서 달려오는 몬스터를 쏘는 총 + 타이쿤 웹 게임입니다. 하루를 버티면 캠프로 돌아와 총, 장비, 시설, 스킬트리를 사고, 준비가 되면 "보스에 도전하기"로 붉은 달의 군주를 잡아 엔딩을 봅니다. 목표 플레이타임은 약 2시간입니다.

- 맵: three.js 3D (지형, 캠프, 자원, 조명과 낮/밤)
- 캐릭터와 몬스터: Canva로 만든 2D 스프라이트
- 수치: `content/data.json` (총 9종, 몬스터 9종, 엘리트 6종, 30일 밸런스)
- 소리: `audio/audio.js` (Web Audio 실시간 합성)

빌드 과정이 없는 정적 사이트입니다. 이 폴더를 그대로 서버에 올리면 됩니다.

```
cd gun-tycoon && python3 -m http.server 8000
```

조작: WASD 이동, 마우스 조준, 클릭 유지 사격, R 재장전, Space 구르기, 1~9 / Q 무기 교체, P 일시정지. 휴대폰은 화면을 끌어서 이동하고 조준과 사격은 자동입니다.
